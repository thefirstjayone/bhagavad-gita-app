# The Bhagavad Gita - Sacred Study Reader

An interactive web application for contemplative study of the Bhagavad Gita featuring:
- **Original Sanskrit Devanagari**
- **IAST Academic Transliteration**
- **Easy Phonetic English** (aa, ee, oo, sh)
- **Word-for-Word Padachheda** with lexical roots and 1905 Babu Bhagavan Das glosses
- **Dual Translations**: 1905 Annie Besant Classic + Modern Direct English
- **Web Audio Tanpura Drone Synthesizer** (C# root + harmonic overtones)
- **Synchronized Audio Chanting**

## Repository Structure
- `index.html`: Complete single-page study application
- `data/chapter_2.json`: Verse data with full word-for-word analysis
